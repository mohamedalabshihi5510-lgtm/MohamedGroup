MOHAMED GROUP WEBSITE — النسخة الأولى القابلة للتشغيل
======================================================

الملفات:
- index.html: الموقع كامل في ملف واحد، ويعمل بدون تثبيت برامج أو خادم.
- README.txt: تعليمات التشغيل والنشر.

التشغيل على الموبايل:
1) فك ضغط ZIP.
2) افتح مجلد mohamed_group_site.
3) افتح index.html بمتصفح Chrome أو متصفح حديث.
4) بعض الخطوط تحتاج إنترنت؛ الموقع نفسه يعمل محليًا، لكن الخط الافتراضي سيظهر عند عدم توفر الإنترنت.

تخصيص رقم واتساب:
1) افتح index.html بمحرر نصوص.
2) رقم واتساب المضاف حاليًا: 201018499486 (01018499486 بصيغة دولية).
3) لو احتجت تغيير الرقم لاحقًا، استخدم الصيغة الدولية أرقام فقط، بدون + أو مسافات.
4) احفظ الملف وجرب إرسال طلب تجريبي.

النشر مجانًا باستخدام GitHub Pages:
1) أنشئ حسابًا على github.com من المتصفح.
2) أنشئ Repository جديدًا باسم mohamed-group-site واجعله Public.
3) ارفع index.html إلى الجذر (Root) للمستودع.
4) افتح Settings ثم Pages.
5) في Build and deployment اختر Deploy from a branch.
6) اختر main و / (root) ثم Save.
7) انتظر ظهور رابط الموقع في صفحة Pages. قد يستغرق النشر بضع دقائق.

بديل أسهل:
يمكن رفع index.html إلى خدمة استضافة مواقع ثابتة مثل Netlify Drop من المتصفح، وفق تعليمات الخدمة الحالية.

ملاحظات مهمة:
- هذه نسخة واجهة متجر وكتالوج وسلة طلبات؛ السلة تحفظ محليًا على الجهاز باستخدام LocalStorage.
- لا يوجد دفع إلكتروني، أو إدارة مخزون مشتركة، أو لوحة تحكم، أو قاعدة بيانات، أو تسجيل دخول في هذه النسخة.
- المنتجات والأسعار غير مؤكدة؛ لا تعرض أسعارًا فعلية قبل إدخال بيانات الشركة.
- قبل الإطلاق التجاري أضف الاسم القانوني، أرقام التواصل، العنوان، البريد، سياسة الخصوصية، الشحن والاسترجاع، والشروط التجارية.
- التصدير الفعلي يتطلب التحقق من التراخيص والاشتراطات الجمركية والصحية في بلد الوجهة.
- لا توجد صور منتجات حقيقية في النسخة الحالية؛ الرموز مؤقتة ويمكن استبدالها بصور الشركة ومنتجاتها.
